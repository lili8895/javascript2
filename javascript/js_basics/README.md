# Основы JavaScript — контрольные точки КТ1–КТ5

Решения всех задач контрольных точек за семестр. Каждая задача лежит в отдельном файле
и выводит результат в консоль.

## Запуск

Нужен [Node.js](https://nodejs.org/) 14+.

```bash
node kt1/task1.js      # одна задача
node run_all.js        # все задачи подряд
node run_all.js kt4    # все задачи одной КТ
```

## Примечания

- **КТ4, задача 6:** id нового пользователя = максимальный id + 1. Пока никого не удаляли,
  это совпадает с «количество пользователей + 1» (очередная запись получает id = 3),
  а после удаления id не повторяются.
- **КТ4, задача 7:** решения сохранены в переменные `task_1` … `task_5`. Файл `products.js`
  содержит массив товаров с полями `id, title, price, count, marks` (marks — массив оценок).
- **КТ4, задача 9:** геттер `phone` возвращает тип номера по длине без знака «+»
  (12 — «Мобильный», 18 — «Городской», нет «+» — «Неизвестный»); сам номер доступен через `phoneNumber`.
- **КТ5, задача 5:** функция принимает необязательную дату, поэтому в демонстрации проверены все 7 дней недели.
